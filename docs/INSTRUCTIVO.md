# Instructivo de ejecución — FarmVille

1. Descomprime el proyecto si lo descargaste como ZIP.
2. Abre **IntelliJ IDEA** y selecciona **Open**.
3. Abre la carpeta donde se encuentra `src/farmville/`.
4. Asegúrate de que el proyecto tenga configurado un JDK.
5. Abre `src/farmville/Main.java`.
6. Ejecuta el método `public static void main(String[] args)` desde el triángulo verde del IDE.
7. Cuando se abra la consola, introduce el nombre de un jugador nuevo o carga una partida anterior si existe.
8. Utiliza el menú numérico para administrar la granja.
9. Selecciona la opción **10. Salir** para guardar la partida en `partida_farmville.txt`.
10. En el próximo inicio, responde `S` si deseas recuperar tu partida guardada.

## Opciones del menú

1. Ver estado de la granja
2. Comprar parcela
3. Sembrar cultivo
4. Cosechar cultivo
5. Comprar animal
6. Alimentar animal
7. Recolectar productos
8. Ver saldo
9. Simular avance de tiempo
10. Salir
